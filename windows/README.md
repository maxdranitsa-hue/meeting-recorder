# Автоматическая запись встреч — Windows

Программа сама замечает начало встречи в Zoom, Google Meet или Яндекс
Телемост, записывает обе стороны и превращает разговор в текст. Нажимать
ничего не нужно.

То же, что делает версия для Mac. В отличие от [watcher/](../watcher/),
запись делает сама программа, а не Zoom — поэтому:

- **работает на чужих встречах**, где вы обычный участник, а не организатор
- не нужно ничьих разрешений внутри Zoom
- записывает и то, что Zoom записать не может

## Что нужно

- Windows 10 или 11
- [Python 3.9+](https://www.python.org/downloads/) — при установке обязательно
  отметьте галочку **Add Python to PATH**
- `ffmpeg` — установщик предложит поставить его сам через winget
- Аккаунт [Deepgram](https://console.deepgram.com/signup) — новым дают **$200
  бесплатно без срока сгорания**, час записи стоит около 46 центов

## Установка

Откройте папку проекта в командной строке и выполните:

```
python setup_windows.py
```

Установщик поставит библиотеки, спросит ключ Deepgram и папку для расшифровок,
**проверит, что звук реально записывается**, и настроит автозапуск вместе с
Windows.

После установки рядом с часами появится иконка:

| Цвет | Что значит |
|---|---|
| зелёный | ждёт начала встречи |
| красный | идёт запись |
| серый | запись выключена |
| жёлтый | не задан ключ Deepgram |

Правый клик по иконке — меню: включить или выключить запись, открыть папку с
расшифровками, посмотреть журнал.

## Как это работает

Звук собеседника берётся через **WASAPI loopback** — это штатный механизм
Windows, который отдаёт копию того, что идёт в колонки или наушники. Ваш звук
при этом не трогается: слышно всё как обычно, громкость работает, наушники
можно переключать на ходу. Отдельно пишется микрофон. В конце обе дорожки
сводятся в один файл и уходят на расшифровку.

Встреча определяется по окну конференции Zoom и по заголовкам вкладок браузера
для Meet и Телемоста. Телефонные звонки не записываются.

## Проверка, если что-то не работает

**Звук не записывается** — запустите проверку захвата:

```
python audio_capture.py --test
```

Пять секунд записи, и программа скажет отдельно про каждую сторону: слышно её
или тишина. Включите на это время видео со звуком и скажите что-нибудь в
микрофон.

- «собеседник: тишина» — звук выводится не на обычное устройство Windows
- «микрофон: тишина» — Параметры → Конфиденциальность → Микрофон → разрешить
  доступ классическим приложениям

**Встреча не определяется** — посмотрите, что видит программа:

```
python meeting_detect.py --list
```

Команда покажет все окна с их заголовками и отметит те, которые считает
встречей. Если ваша встреча идёт, а в списке она не отмечена — покажите вывод
Claude Code, признак поправить несложно.

**Журнал:** `%APPDATA%\MeetingTranscriber\transcriber.log`

## Честно о состоянии

Эта версия написана и проверена настолько, насколько это возможно без Windows
под рукой: логика сведения дорожек, расшифровка и именование файлов проверены
на реальных данных, поведение модулей вне Windows тоже. **Сам захват через
WASAPI и определение окон на живой Windows не проверялись.**

Поэтому первым делом запустите `python audio_capture.py --test` — она покажет
правду за пять секунд. Если что-то не сходится, откройте папку в Claude Code
и покажите ему вывод команд выше: в файле `CLAUDE.md` в корне проекта для него
написано, как это чинить.

## Запись и собеседники

Программа пишет звук мимо Zoom, поэтому **индикатора записи участники не
увидят**. Предупреждать их — на вас, и во многих странах это требование
закона, а не вежливость.
