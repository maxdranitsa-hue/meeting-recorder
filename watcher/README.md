# Транскрибатор встреч

Работает на **Windows, macOS и Linux**.

Программа следит за папкой, куда сохраняются записи встреч. Появилась новая
запись — она сама превращается в текст и ложится в вашу папку. Ничего нажимать
не нужно.

```
2026-08-09 14-30 — созвон с клиентом.md
```

## Как это работает

Записывает встречу сам Zoom, а программа подхватывает готовый файл. Один раз
настраиваете — дальше всё идёт само:

1. В Zoom включена локальная запись
2. Zoom сохраняет запись в свою папку
3. Программа замечает новый файл и отправляет его на расшифровку
4. Текст с разделением по говорящим появляется в выбранной вами папке

Оригинальную запись программа не трогает.

## Что нужно

- Python 3.9 или новее ([скачать](https://www.python.org/downloads/) — на Windows
  при установке отметьте галочку **Add Python to PATH**)
- Аккаунт [Deepgram](https://console.deepgram.com/signup) — новым дают **$200
  бесплатно без срока сгорания**, часа записи стоит около 46 центов
- Желательно `ffmpeg` — он вытаскивает звук из видеозаписи, без него загрузка
  идёт дольше. Windows: `winget install ffmpeg`, macOS: `brew install ffmpeg`

## Установка

```bash
python setup_watcher.py
```

Программа спросит ключ, папку с записями и папку для расшифровок, предложит
настроить автозапуск вместе с компьютером — и на этом всё.

## Настроить Zoom, чтобы записи появлялись сами

Zoom → Настройки → **Запись**:

- Проверьте путь сохранения — его же укажете программе
- Включите **«Записывать отдельный аудиофайл»** — расшифровка пойдёт быстрее
  и дешевле, чем из видео

Zoom → Настройки → **Общие** → включите автоматическую запись при старте
встречи, если хотите, чтобы вообще ничего не нажимать.

**Важное ограничение Zoom:** записывать может организатор встречи или участник,
которому организатор это разрешил. Это правило самого Zoom, обойти его нельзя.
На своих встречах вы организатор — там всё работает.

## Где что лежит

| | Windows | macOS |
|---|---|---|
| Настройки | `%APPDATA%\MeetingTranscriber\config.json` | `~/Library/Application Support/MeetingTranscriber/config.json` |
| Журнал | там же, `transcriber.log` | там же, `transcriber.log` |
| Автозапуск | ярлык в папке «Автозагрузка» | LaunchAgent |

## Если что-то не работает

Сначала посмотрите журнал — путь выше.

**Ничего не расшифровывается.** Проверьте, что в папке действительно появляются
файлы записей и что путь в настройках совпадает с путём в настройках Zoom.

**«Deepgram отклонил ключ».** Ключ неверный или на аккаунте кончились средства.
Перезапустите `python setup_watcher.py` и введите ключ заново.

**Старые записи не расшифровались.** Так и задумано: при первом запуске
программа помечает всё, что уже лежит в папке, и берёт в работу только новые
встречи — иначе первый же запуск выставил бы счёт за весь архив. Чтобы
расшифровать старое, удалите файл `processed.json` рядом с настройками.

**Файл больше 2 ГБ** Deepgram не примет — включите в Zoom отдельный аудиофайл,
он в разы меньше видео.

## Автоматизм на macOS

На маке есть версия лучше — она пишет встречи сама, не полагаясь на запись
Zoom, и работает даже когда вы просто участник. Смотрите корневую папку
проекта.
