# Запись звонков (macOS)

Приложение для macOS, которое само записывает ваши видеовстречи и превращает
их в текст.

Началась встреча в Zoom, Google Meet или Яндекс Телемост — запись включилась
сама. Встреча закончилась — через минуту в выбранной папке лежит файл с полной
расшифровкой разговора, разделённой по говорящим.

Ничего не нужно нажимать. Иконка 🎙 в строке меню, и всё.

```
2026-08-09 14-30 Zoom — обсуждение бюджета на квартал.md
```

## Что нужно

- **macOS 14.2 или новее** — обязательно, механизм записи звука появился именно
  в этой версии. Более старый Mac — берите [watcher/](watcher/)
- Аккаунт [Deepgram](https://console.deepgram.com/signup) — новым дают **$200
  бесплатно без срока сгорания**. Час записи стоит около 46 центов, так что
  этого хватает надолго
- [Homebrew](https://brew.sh) — если его нет, установщик подскажет

Windows и Linux — вам в папку [watcher/](watcher/), там кросс-платформенная
версия.

## Установка

Самый простой способ — открыть папку проекта в Claude Code и сказать:

> установи это приложение

Он всё сделает сам: в папке лежит инструкция для него.

Вручную — одна команда:

```bash
bash install.sh
```

Дальше:

```bash
open "$HOME/Applications/Запись звонков.app"
```

При первом запуске приложение спросит ключ Deepgram (само откроет страницу
регистрации) и папку для расшифровок.

**При первой записи macOS запросит три разрешения — нужно разрешить все:**
микрофон, запись звука с этого компьютера, управление Google Chrome.

Чтобы приложение включалось вместе с компьютером: Системные настройки →
Основные → Элементы входа → добавить «Запись звонков».

## Как это работает

Приложение раз в несколько секунд проверяет, идёт ли встреча: запущен ли
служебный процесс Zoom, открыта ли в Chrome вкладка с активным звонком в Meet
или Телемост. Телефонные и FaceTime-звонки не записываются.

Во время встречи пишутся обе стороны — ваш микрофон и звук собеседника — в один
файл. Звук снимается **копией**: ваш выход не переключается, вы слышите
собеседника как обычно, громкость работает, наушники можно менять на ходу.

После встречи запись уходит в Deepgram, а текст с разделением по говорящим
сохраняется в вашу папку. Аудиофайл удаляется, остаётся только текст.

Если установлен Claude Code, он подберёт файлу осмысленное имя по теме
разговора. Если нет — имя будет по дате и длительности.

## Меню

| Пункт | Что делает |
|---|---|
| Запись звонков | Выключить или включить запись, не закрывая приложение |
| Открыть папку с расшифровками | Открыть папку в Finder |
| Изменить папку… | Выбрать другое место для файлов |
| Изменить ключ Deepgram… | Заменить ключ |
| Показать журнал | Открыть лог — туда пишутся все ошибки |

Состояния иконки: `🎙 вкл` — ждёт встречу, `🔴 REC` — идёт запись,
`🎙 выкл` — приостановлено, `⚠️ настрой` — не задан ключ.

## Если что-то не работает

Журнал: `~/Library/Logs/meeting-recorder.log`

**Собеседника не слышно в расшифровке.** Не выдано разрешение на запись звука.
Системные настройки → Конфиденциальность и безопасность → Запись звука →
включить «Запись звонков». В Zoom дополнительно: Настройки → Звук → Динамик =
«Как в системе».

**Zoom записывается, а Meet и Телемост не замечаются.** Нет разрешения на
управление Chrome: Системные настройки → Конфиденциальность → Автоматизация.

**В журнале «Deepgram отклонил ключ».** Ключ неверный или на аккаунте
закончились средства — проверьте в консоли Deepgram.

Проще всего — открыть папку в Claude Code и описать проблему словами: там
лежит инструкция по диагностике.

## Приватность

Ключ Deepgram и настройки лежат только на вашем компьютере, в
`~/Library/Application Support/MeetingRecorder/config.json`. Записи уходят
на расшифровку в Deepgram под **вашим** аккаунтом и больше никуда. Никакой
телеметрии в приложении нет.

## Важно про запись собеседника

Приложение записывает обе стороны разговора. Предупреждать собеседников о
записи — ваша ответственность, и во многих странах это прямое требование
закона. Используйте на рабочих встречах, где запись уместна и о ней сказано.
