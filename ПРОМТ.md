# Что вставить в Claude Code

Скачайте папку проекта, откройте её в Claude Code и вставьте один из промтов
ниже. Дальше Claude всё сделает сам — читать код не нужно.

---

## Если у вас Mac

```
Установи приложение для автоматической записи и расшифровки моих
видеовстреч. Инструкция для тебя — в файле CLAUDE.md в корне проекта.

Объясняй простыми словами и скажи, что мне нажать.
```

Получится приложение в строке меню: встреча началась — запись пошла сама,
закончилась — текст лёг в вашу папку. Работает и когда вы не организатор
встречи.

Нужна **macOS 14.2 или новее**.

---

## Если у вас Windows

```
Установи транскрибатор встреч из папки watcher. Инструкция для тебя —
в файле CLAUDE.md в корне проекта, раздел про watcher.

У меня Windows. Объясняй простыми словами и скажи, что мне нажать.
```

Получится программа, которая следит за папкой Zoom: записанная встреча сама
превращается в текст. Запускается вместе с компьютером.

Zoom должен записывать встречу — это делает организатор. На своих встречах
включите автозапись, и дальше всё идёт само.

---

## Если хотите на Windows такой же автомат, как на Mac

Версия для Windows опирается на запись Zoom. Можно сделать, чтобы программа
писала звук сама и не зависела от Zoom — тогда она будет работать на любых
встречах, включая чужие.

Это уже задача на доработку, и она вполне посильна для Claude Code:

```
В этом проекте есть автоматическая запись встреч для macOS (корень проекта)
и транскрибатор папки для Windows (папка watcher).

Сделай для Windows полноценный аналог macOS-версии: чтобы программа сама
замечала встречу и писала звук, не полагаясь на запись Zoom.

Техническая основа, которую стоит использовать:
- захват звука динамиков — WASAPI loopback через PyAudioWPatch
- микрофон — вторым потоком, свести с системным звуком в один моно-файл
- определение активной встречи — по запущенным процессам (Zoom.exe)
  и заголовкам окон Chrome для Meet и Телемоста
- иконка в трее — pystray
- расшифровку, именование файлов и настройки бери из существующего кода
  в папке watcher, не переписывай их заново

Сначала покажи план и скажи, что именно ты собираешься переиспользовать.
```

## Что понадобится в любом случае

**Ключ Deepgram** — сервис, который превращает речь в текст.
Регистрация: https://console.deepgram.com/signup

Новым аккаунтам дают **$200 бесплатно, они не сгорают**. Час записи стоит
около 46 центов — этого хватает на сотни часов встреч. Ключ хранится только
на вашем компьютере, записи уходят на расшифровку под вашим аккаунтом.

**Предупреждайте собеседников о записи.** Во многих странах это требование
закона, и это просто нормально по-человечески.
